# SIH25170 Simple User Flow

## Goal

A non-technical user should be able to complete the main task without
training.

## Flow A --- Select an Area

### Step 1

User sees:

**Let's explore your area**

Buttons: - Select area on map - Upload an image

### Step 2

User selects location.

Do not require coordinates manually.

### Step 3

System shows available EO imagery/date options in simple language.

Example:

**Earlier image --- May 2022**

**Recent image --- May 2025**

Technical sensor information is optional.

### Step 4

User taps:

**Analyze this area**

### Step 5

Show progress:

-   Getting image
-   Checking the area
-   Finding changes
-   Preparing results

Do not show confusing model terminology.

### Step 6

Show:

**What we found**

-   Vegetation decreased
-   Buildings increased
-   Water had no major change

### Step 7

User can tap a result.

The image highlights the relevant region.

### Step 8

User can ask:

"Why did vegetation decrease?"

The AI answers in simple language.

## Flow B --- Upload Image

1.  Tap Upload image.
2.  Select file.
3.  Preview image.
4.  Confirm.
5.  Analyze.
6.  View results.
7.  Ask questions.

## Flow C --- Compare

1.  Choose earlier image.
2.  Choose later image.
3.  Tap Compare.
4.  Show side-by-side or swipe comparison.
5.  Show simple change summary.
6.  Let user inspect highlighted areas.

## Flow D --- Expert Details

At any result screen:

**View technical details**

opens a secondary panel/page.

The default screen remains simple.

## UX Rule

Never make the user answer technical questions unless the system truly
needs them.

If a sensible default exists, use it.
