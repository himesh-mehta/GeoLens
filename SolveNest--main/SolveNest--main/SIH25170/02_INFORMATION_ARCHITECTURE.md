# SIH25170 Information Architecture

## Default Navigation

Keep navigation short.

Recommended: - Home - My Areas - Compare - History - Help

Optional: - Settings

Do not create separate navigation items for every technical feature.

## Home

Purpose: Help the user start quickly.

Show: - Greeting - Select area - Upload image - Recent area, if
available - Simple explanation of the product

Primary actions: - Select an area - Upload EO data

## My Areas

Purpose: Let users save and reopen areas they care about.

Show: - Area name - Last analysis date - Simple status

## Compare

Purpose: Compare two observations.

Show: - Earlier image - Later image - What changed - Visual comparison

## History

Purpose: Reopen previous analyses.

Keep it simple: - Area - Date - Analysis type - Status

## Help

Explain the product in simple language.

Include: - What is satellite imagery? - What can this system tell me? -
How to select an area - How to ask questions - What the results mean

Avoid technical documentation on the main Help screen.

## Settings

Only include useful settings: - Language - Appearance - Account - Data
preferences

## Expert Mode

Expert Mode should be reachable from an analysis through a button such
as:

**View technical details**

It should not dominate navigation.

## Navigation Rule

At all times the user should know: - where they are - what area they are
viewing - what step they are on - what to do next
