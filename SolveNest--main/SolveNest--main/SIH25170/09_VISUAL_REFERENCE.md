# SIH25170 Visual Reference

## Approved Direction
Use a simple, light Earth Observation application that feels trustworthy and approachable.

The reference image is a visual direction, not a pixel-perfect copy.

## Layout
- Small left navigation
- Large central EO image/map
- Simple findings below or beside the image
- AI assistant on the right on desktop
- Clear language selector
- Minimal controls

## Visual Character
Prefer:
- Light background
- White surfaces
- Soft borders
- Green as the main action/nature accent
- Blue for information/water
- Purple used sparingly for AI/technical context
- Comfortable whitespace
- Readable typography
- Medium rounded corners

Avoid:
- Dark futuristic dashboards
- Neon colors
- Glassmorphism
- Excessive gradients
- Glowing borders
- Floating 3D elements
- Excessive shadows
- Huge headings
- Decorative AI robots

## Content Priority
1. Your Area
2. Main EO image
3. What we found
4. What changed
5. Ask a question
6. Technical details only when requested

Functionality, accessibility and clarity have priority over visual similarity.
